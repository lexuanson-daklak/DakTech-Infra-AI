# DakWater AI – MVP v0.7.1

## Chuỗi quản trị
Nguồn nước → Nhà máy/trạm cấp nước → Tuyến ống → Vùng phục vụ → Vận hành/chất lượng → Đầu tư.

## Trung tâm xuất dữ liệu
Bắt buộc theo DATA-EXPORT-STANDARD-v1.0:
CSV + Excel + JSON + GeoJSON (khi có tọa độ) + FULL DATA PACKAGE ZIP.

Người dùng nghiệp vụ tải dữ liệu trực tiếp trên Streamlit, không cần vào GitHub.
