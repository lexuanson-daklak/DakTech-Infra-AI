# QUY CHUẨN GIAO DIỆN TIẾNG VIỆT v1.0

Áp dụng bắt buộc cho toàn bộ hệ sinh thái GitHub + Streamlit.

1. Giao diện nghiệp vụ dùng tiếng Việt làm ngôn ngữ chính.
2. Tên thương hiệu như DakWater AI, DakDrain AI được giữ nguyên.
3. Thuật ngữ tiếng Anh/chữ viết tắt chỉ dùng khi cần và phải có nghĩa tiếng Việt.
4. Không hiển thị tên file kỹ thuật như `water_dashboard`, `asset_360`, `system_views` cho người dùng nghiệp vụ.
5. `Dashboard` trên giao diện đổi thành **Bảng điều hành**.
6. Mã trạng thái kỹ thuật phải hiển thị bằng tiếng Việt.
7. Mỗi phân hệ bắt buộc có **Trung tâm xuất dữ liệu**.
8. Người dùng nghiệp vụ không cần vào GitHub để lấy dữ liệu.
9. Phân hệ không phải trọng tâm được gom vào nhóm **Phân hệ tạm dừng**, không chiếm menu chính.
10. GitHub phục vụ quản trị kỹ thuật; Streamlit phục vụ khai thác nghiệp vụ.
