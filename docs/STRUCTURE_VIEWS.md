# Các chế độ xem cấu trúc DakTech Infra AI

Mục tiêu: giúp người dùng không chuyên lập trình vẫn hiểu nhanh hệ thống.

## 1. View tổng quan hệ sinh thái
Nhìn nền tảng mẹ và các phân hệ con.

## 2. View cây sản phẩm
Nhìn theo chức năng quản lý nhà nước và sản phẩm.

## 3. View cây thư mục GitHub
Nhìn theo nơi lưu mã, dữ liệu demo, tài liệu và kiểm thử.

## 4. View GitHub ↔ Streamlit
Đối chiếu file/thư mục GitHub với màn hình mà người dùng thấy trên Streamlit.

## 5. View luồng dữ liệu
Theo dõi đường đi của dữ liệu từ hồ sơ nguồn đến xác minh và dashboard.

## 6. View trạng thái phân hệ
Theo dõi mức trưởng thành và bước phát triển tiếp theo của từng phân hệ.

### Nguyên tắc
Cây sản phẩm và cây kỹ thuật là hai góc nhìn khác nhau. Không ép hai cây phải giống hệt nhau.
