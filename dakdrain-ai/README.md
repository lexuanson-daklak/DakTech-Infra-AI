# DakDrain AI (Quản lý thoát nước và xử lý nước thải)

**Phân hệ quản lý thoát nước và xử lý nước thải thuộc DakTech Infra AI**

## Định hướng chức năng

- Quản lý tuyến cống.
- Hố ga, cửa xả, trạm bơm.
- Lưu vực thoát nước.
- Điểm ngập.
- Công trình xử lý nước thải.
- Sự cố, bảo trì và nhu cầu đầu tư.
- Hồ sơ pháp lý và nguồn dữ liệu.

## Trạng thái

Đang ở mức khung phân hệ trong nền tảng mẹ; sẽ phát triển sâu sau khi DakCemetery AI hoàn thiện chuỗi quản trị dữ liệu thực tế.
